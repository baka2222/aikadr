# Оформление aikadr

Начальный растровый ассет: `frontend/public/brand/aikadr-square.png`. Квадратная версия подготовлена по изображению пользователя через встроенный imagegen, без платного стороннего API. Это адаптация изображения, а не гарантированно точная пиксельная обрезка оригинала.

Задача для генерации: сохранить тёмно-синий фон, золотую эмблему киноплёнки и надпись aikadr; оформить логотип в квадрате, не добавляя новых элементов. Исходное изображение использовано как reference.

Супер-администратор может заменить изображение в `/admin` → «Оформление», загрузить фон, выбрать сезонную тему и цвет акцентов. Настройки сохраняются в PostgreSQL, загруженные изображения — в `kadr_data`. По умолчанию используется тема «Полночь», также доступны «Зимняя премьера» и «Северное сияние».

В интерфейсе используются CSS-анимации появления, наведения и зимнего фона. Настройка устройства `prefers-reduced-motion` отключает движение. Внешние шрифтовые сервисы не требуются.
